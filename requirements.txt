# --- macOS y Windows ------------------------------------------------------------------
# Ningun paquete de esta lista es exclusivo de un sistema, asi que el archivo es UNO
# solo y no lleva marcadores de entorno. Lo que si cambia son tres cosas, y las tres
# estan verificadas:
#
# 1. **`torch` en Windows desde PyPI es CPU.** La rueda `win_amd64` pesa 116 MB;
#    las de CUDA viven en `https://download.pytorch.org/whl/cu<version>` y no se
#    instalan con este archivo. Para reentrenar con GPU NVIDIA:
#        pip install torch --index-url https://download.pytorch.org/whl/cu124
#    No hace falta para nada mas: los informes y los tableros solo hacen inferencia.
# 2. **En macOS `torch` trae MPS, y conviene NO usarlo para reentrenar.** Medido en
#    un M4 Max: CPU 5,5 s por epoca y pliegue con pico de 3,3 GB; MPS 19,6 s y pico
#    de 11,2 GB. Es 3,6x mas lento y 3,4x mas hambriento. Ver `docs/REQUISITOS-MINIMOS.md`.
# 3. **Las ruedas binarias grandes (`torch`, `geopandas`, `pyarrow`, `scipy`) existen
#    para los dos.** No hace falta compilador en ninguno de los dos sistemas.
