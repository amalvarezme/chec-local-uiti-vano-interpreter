## Runtime notes

- **Repository root.** Resolve it with `git rev-parse --show-toplevel 2>/dev/null || pwd` and run every command from there. Do not trust the process working directory: in OpenCode Desktop it can resolve to the app data directory instead of the project.
- **Environment.** Every CLI verb runs as `PYTHONPATH=src .venv/bin/python -m ...`. Do not reach for bare `python`/`python3` first, and do not report the environment as missing just because they cannot import `chec_local_interpreter`: the virtualenv-prefixed form is this repository's supported local command.

- No model training and no Optuna search.
